      <h2>Projects</h2>

      <article class="card">
        <h3>Fingerprint Authentication System</h3>
        <p>I soldered a Raspberry Pi 5 to an optical fingerprint sensor to build a hardware-based biometric authentication system that can store up to 1,000 unique fingerprints.</p>
        <ul>
          <li>Wrote software to enroll, delete, save, and verify fingerprint templates for user authentication.</li>
          <li>Integrated a fingerprint-matching library to compare scanned fingerprints against ones that were already enrolled.</li>
          <li>Added features that apply "salt" to the prints to make them harder to read, to simulate real-world authentication.</li>
          <li>Researched machine learning techniques, including convolutional neural networks for authentication and the ORB feature detection algorithm for finding and marking significant points on fingerprints.</li>
        </ul>
